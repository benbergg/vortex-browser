## 选择时的困惑

- `pnpm --filter vortex-bench playground` 的过滤器没有匹配到项目；读取 `packages/vortex-bench/package.json` 后确认实际包名是 `@vortex-browser/bench`。不过 5173 已有正确的 Vite 进程，因此没有再次启动第二个服务。
- 第一次调用 `vortex_vortex_tab_create` 返回 `No current window`；当时当前浏览器是 Microsoft Edge。调用 `vortex_vortex_browser` 切换到 Google Chrome 后重试 `vortex_vortex_tab_create` 才成功。
- `vortex_vortex_observe` 返回的级联菜单 ref 带动态 hash，不能沿用旧 ref，所以每一级点击后都重新获取快照。
- 任务 5 题目路由 `#/el-date-picker-date-range` 在靶场中没有控件，页面实际链接使用 `#/el-date-picker-daterange`；需要先用 `vortex_vortex_extract` 和 `vortex_vortex_evaluate` 确认不是加载延迟，再按页面实际链接继续。
- `vortex_vortex_query` 在 transfer 按钮上只能读到空按钮名，无法直接判断方向；改查 SVG path 的 `d` 属性后确认第二个按钮是向右箭头。
- `vortex_vortex_query` 的 `mode=css` 对 web.dev 的 `h1` 查询返回 0 个元素；改用 `mode=text` 才得到主标题的真实 DOM path，再给 `vortex_vortex_screenshot` 使用 CSS selector 截单元素。
- `vortex_vortex_debug_read` 的 network 参数一开始误放为 `filter.network.pattern`，工具实际要求 `filter.pattern`；这是唯一一次浏览器工具参数错误，按错误提示修正后继续。
