## 关键结论(回答后续场景能否覆盖)

### 图表在哪?canvas/svg?
- **当前评测可直接覆盖的图表=0 个**。
- 多个 app 有「**看板**」容器(VOC工作表看板 / 退款管理大脑看板 / 啾啾测试看板 / 产品体验大盘…),但其中:
  - VOC工作表看板:**0 张图表,空**(2026-03-10 最后更新)
  - 退款管理大脑看板:4 张**图文卡片**(图片+文字,IMG 标签,非 echarts canvas)
  - 啾啾测试看板:**0 张图表,空**(2024-10-14 最后更新)
  - 产品体验大盘 / 产品体验洞察:**未点开**,看名字像图表,待后续轮次验证。
- 所有已探页面 `canvas=0`,`<svg>` 只有 2~3 个图标级别元素,**没有现成的 echarts/svgrender 图表**。
- 看板都支持「**添加图表**」按钮,说明配置层有 chart 类型可选,但需要构造数据源才能出图。

### 流程图/画布在哪?决定 mode=flow 能否做
- **`工作流` → 任一 workflow demo(如"工作流演示")→ 顶部 `流程` 按钮 → dialog 内的 `流程布局`** 是流程画布入口。
- 但本次 recon 点击 `流程布局` 后 DOM 未新增 canvas/svg/x6-graph,**未确认是弹窗式画布还是页面级画布**,需要二次确认。
- 副线索:工作流 demo 的主区域是「**节点状态运行列表**」(每个工单当前在哪个节点),非画布视图。

### canvas 电子表格有没有?决定 mode=sheet 能否做
- **本次未发现 canvas 电子表格**。所有已探页面都是普通 DOM `<table>`(工单测试表0611 / 退款管理子表 / 工作流演示 节点状态表),无类 Excel 的 canvas 网格。
- 建议下一轮次重点探:`计算组件`(看名字可能有特殊控件) / `新评价模板3.2` / `售后管理` / `ERP工作台`,这些名字不像普通表格。

### 拖拽在哪?
- 已探页面**无明显拖拽**。左侧菜单有 `dragItem` / `dragWorksheet-item` className 提示**菜单项本身可拖拽排序**(admin 配置),但普通用户视图下未观察到行拖拽。
- 看板卡的"添加图表→拖入位置"属于 admin 配置,recon 不深入。

### 识别不了的盲区
- **`observe` 全页超时**(`vortex_observe` 在某些 tab 上 30s 超时),改用 `vortex_extract` + `vortex_query` + `vortex_evaluate` 三角验证。
- 看板卡内部细节:**图文卡片** 的图片是 `<img>` 还是背景图,observe 看不到,需要 evaluate 直接读 DOM 属性确认。
- **`流程布局`** 点开后是否渲染了画布,本次未拿到证据(extract 文本未变),可能是异步加载或弹窗被遮,需要二次确认。
- **「新评价模板3.2 / 3.1 / 0412 / 0411」「售后管理」「ERP工作台」「计算组件」「活动返现」** 一类名字特殊的 app 未点开,可能含表单/电子表格/画布等未覆盖组件,留待下一轮次。
